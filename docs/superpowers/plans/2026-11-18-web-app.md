# Heritage Atlas Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the "Night Atlas" interactive web application in SvelteKit with a MapLibre GL JS v5 3D globe, smooth country fly-to transitions, category-styled clustered site markers, practical "what to expect" country panels, site detail cards, and deep-linked routes.

**Architecture:** A static SvelteKit application (`web/`) reading the prebuilt JSON/GeoJSON files in `web/static/data/`. A single persistent MapLibre GL JS v5 canvas switches between an auto-rotating 3D globe at world zoom and a dimmed-world country focus view with on-demand GeoJSON clustering, synchronized with Svelte state and shareable URLs (`/`, `/country/[iso3]`, `/country/[iso3]/site/[siteId]`).

**Tech Stack:** Node.js 22 LTS, SvelteKit 2 + Svelte 5 (`@sveltejs/adapter-static`), TypeScript, MapLibre GL JS v5 (`maplibre-gl`), `pmtiles`, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-18-heritage-atlas-design.md` and `docs/superpowers/plans/2026-11-18-data-contract.md`

## Global Constraints

- Aesthetic must match the "Night Atlas" direction: deep navy space backdrop (`#03060f` → `#12264a`), dark-blue to gold (`#1b2d4a` → `#f5c76b`) country richness fills, Cormorant Garamond serif headings, Inter UI body, frosted glass panels (`backdrop-filter: blur(14px)`).
- Top-5 list on the idle world panel must be labelled factually `"Most heritage sites"`, never `"Best"`.
- Richness computation and country scoring must be isolated in `web/src/lib/data/richness.ts` so the v2 preference-scoring round can swap the coloring function client-side without touching map or panel components.
- Respect `prefers-reduced-motion: reduce` (disable globe auto-rotation and use `duration: 0` on camera transitions).
- Initial page load must fetch only `countries.json` and `boundaries.geojson`; per-country `sites/{ISO3}.geojson` is fetched on demand when entering a country.
- Every site card must display proper source/image license attribution and a category fallback illustration when `image` is `null`.

## Review Focus

- Direct navigation / deep link to `/country/ITA/site/whs-91` or invalid code `/country/ZZZ`: valid deep links must load `countries.json`, fly/jump to Italy, load `sites/ITA.geojson`, and open the site card for `whs-91`; unknown ISO3 or `siteId` must show a clear non-crashing fallback state with a "Back to globe" action.
- Rapid country switching (clicking "Explore France" then immediately switching to "Japan" before `FRA.geojson` finishes loading): stale fetches must be ignored via request token / `AbortController` so Japan never renders France's markers.
- Category filter interaction with active site selection: toggling a category chip filters both the map markers and the panel's site list; if the currently open site card belongs to a filtered-out category, the filter either clears the card or stays consistent without orphaned highlights.
- Antimeridian and small-country camera bounds (e.g. Fiji `west > east`, or Vatican/Malta tiny bbox): `bboxToCameraBounds` must normalize antimeridian longitudes and apply a `maxZoom: 11` cap so tiny countries don't zoom into an unreadable 10-meter square.
- Keyboard and mobile touch usability: `Escape` closes the open site card first, then exits country view back to the globe; on mobile (`< 768px`), first tap on a country previews it in the bottom sheet and tapping `"Explore {country} →"` enters the country view.

- `web/package.json`, `web/svelte.config.js`, `web/vite.config.ts`, `web/tsconfig.json` — SvelteKit static build + Vitest configuration

- `web/src/lib/data/richness.ts` — Isolated country color/score selector (`getCountryScore`, `scoreToColor`, `getTopCountries`)
- `web/src/lib/data/loader.ts` — Data loader with in-memory cache and `AbortController` race protection for `sites/{ISO3}.geojson`
- `web/src/lib/data/search.ts` — Country type-ahead search (name, ISO3, aliases)
- `web/src/lib/map/style.ts` — Custom MapLibre "Night Atlas" style specification (globe projection, atmosphere, Protomaps/vector basemap layers, country fill & dim layers, clustered site layers)
- `web/src/lib/map/camera.ts` — `bboxToCameraBounds` (antimeridian-safe, min-span padded), auto-rotation controller, `prefers-reduced-motion` detection
- `web/src/lib/components/AtlasMap.svelte` — MapLibre GL v5 canvas component (globe mode, hover/selection feature-state, fly-to, clustered markers)
- `web/src/lib/components/WorldPanel.svelte` — World view glass panel (idle invitation + "Most heritage sites" top-5, hovered/tapped country preview, search box)
- `web/src/lib/components/CountryPanel.svelte` — Country view panel / mobile bottom sheet (header, 8 category filter chips with counts, "What to expect" practical block, scrollable site list)
- `web/src/lib/components/SiteCard.svelte` — Site detail card (image or category artwork fallback, summary, UNESCO/In-Danger badge, fame indicator, Wikipedia & UNESCO links, attribution line)
- `web/src/routes/+layout.ts`, `web/src/routes/+layout.svelte` — Persistent atlas shell keeping the MapLibre instance alive across route transitions
- `web/src/routes/+page.svelte` — World view route (`/`)
- `web/src/routes/country/[iso3]/+page.svelte` — Country view route (`/country/{ISO3}`)
- `web/src/routes/country/[iso3]/site/[siteId]/+page.svelte` — Site deep-link route (`/country/{ISO3}/site/{siteId}`)

```typescript
import { describe, expect, it } from 'vitest';
import { resolveRouteState } from './routing';
import type { CountrySummary } from './types';

const countries = [{ iso3: 'ITA', name: 'Italy' }] as CountrySummary[];

describe('resolveRouteState', () => {
	it('resolves root route to world view', () => {
		expect(resolveRouteState(countries, {})).toEqual({
			status: 'world',
			country: null,
			siteId: null
		});
	});

	it('resolves case-insensitive ISO3 and optional siteId', () => {
		const res = resolveRouteState(countries, { iso3: 'ita', siteId: 'whs-91' });
		expect(res.status).toBe('country');
		expect(res.country?.iso3).toBe('ITA');
		expect(res.siteId).toBe('whs-91');
	});

	it('returns not-found for unknown ISO3 without throwing', () => {
		const res = resolveRouteState(countries, { iso3: 'ZZZ' });
		expect(res.status).toBe('not-found');
		expect(res.country).toBeNull();
	});
});
```
